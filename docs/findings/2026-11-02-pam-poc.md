# 自作 PAM モジュールを sudo から load して Touch ID で通す PoC

- Date: 2026-11-02
- 対象: [poc/pam](../../poc/pam/) (`pam_poc.so`、Rust `cdylib` + C / Objective-C shim)
- 環境: macOS 26.5.2 (25F84、本記録の作成時点のバージョン)、`/etc/pam.d/sudo_local` に `auth sufficient /usr/local/lib/pam/pam_poc.so` を先頭の認証行として追加

## 判明した事実

- `/etc/pam.d/sudo_local` に書いた自作モジュール (ad-hoc 署名の `.so`) を sudo が load して `pam_sm_authenticate` を呼ぶ
- PAM conversation の `PAM_TEXT_INFO` で送ったメッセージは、sudo を叩いた tty に表示される
- sudo プロセス内から `KERN_PROCARGS2` で sudo の argv、`KERN_PROC_PID` (ppid) と `proc_pidpath` で sudo から launchd (PID 1) までの祖先チェーンを取得できる
- AppKit を PAM モジュール内で初期化すると、`running setugid(), which is not allowed` のログとともに sudo プロセスごと exit する。sudo のコマンドは実行されない
- euid=root のまま `LAContext` を評価すると `LAError code=-7 Biometry is not enrolled` になる
- 評価の間だけ `seteuid(getuid())` で呼び出しユーザに落とし、評価後に `seteuid(0)` で戻すと、Touch ID ダイアログが出る
- policy `LAPolicyDeviceOwnerAuthenticationWithBiometricsOrCompanion` で、ダイアログの本文 (`localizedReason`) に `sudo <argv>` を出せる
- `localizedFallbackTitle` を「詳細を確認」にしたボタンの押下は `LAErrorUserFallback` (-3) で返る
- Touch ID 成功でモジュールが `PAM_SUCCESS` を返し、sudo はパスワードを聞かずにコマンドを実行する
- Touch ID ダイアログはクリック無しでタッチに反応した (フォーカスの問題は再現しなかった)
- モジュールで承認した後、sudo の timestamp (`timestamp_timeout`) が通常どおり効き、期間内の次の sudo は認証を求めない

## 実用的な示唆 / ベストプラクティス

- AppKit を使う処理 (ブラウザの `open`、window のフォーカス操作) は PAM モジュールに入れず、sudo プロセス外の helper で行う。PAM 内でプロセスを落とすと後続のパスワード認証にも流れず、sudo が使えなくなる
- LAContext の評価は seteuid で呼び出しユーザに落としてから行う
- fallback ボタンは「詳細を確認」の入口に転用でき、policy が生体 / companion の系ならパスワード入力には行かない
- 承認後の無認証期間はモジュールで扱わなくても sudo の timestamp が担う

## 検証の詳細

### 観測マトリクス

| 項目 | 結果 |
|---|---|
| `sudo_local` からの load | load される |
| `PAM_TEXT_INFO` の表示先 | sudo を叩いた tty |
| argv / 祖先チェーンの取得 | sudo から PID 1 まで取得できた |
| AppKit の初期化 | `running setugid(), which is not allowed` で sudo ごと exit |
| euid=root での LAContext | `-7` (Biometry is not enrolled) |
| seteuid で落としての LAContext | Touch ID ダイアログが出る |
| 「詳細を確認」の押下 | `-3` (`LAErrorUserFallback`) |
| Touch ID 成功 | `PAM_SUCCESS`、パスワード不要でコマンド実行 |
| クリック無しでのタッチ | 反応する |
| 承認後の sudo timestamp | 効く |

### 未観測

- `sudo -n` (非対話) での呼び出しの有無と表示
- GUI アプリから起動した sudo での `PAM_TEXT_INFO` の送出先
- キャンセル時のエラーコード
